# teroir.com promise audit (2026-11-12)

**Summary**
1. 51 promises across 7 pages: **4 GAP, 15 PARTIAL, 9 NOT-CODE, 23 MET.** Every number on the site matches FACTS.md; the shortfalls are in what the product does.
2. Top risk 1 (GAP, plan exists): "Every chore photo doubles as a property inspection. Damage shows up in the photos before anyone files a ticket." It sits under "The numbers" on /property-management and reads as live. On main the grader is told to pass building damage (prompts/photo_eval.v4.txt:148-155). The damage watch exists only on branch plan/photo-damage-tickets and is not merged or switched on.
3. Top risk 2 (PARTIAL): a second operator can't be onboarded as a product today. "Live today", "Apply for the beta" and "we set up each portfolio with you" all assume it can. PM.BOS is one install on one Mac (129 files hard-code /Users/operator, 0 systemd units, launchd only). Its only data source is PadSplit, read through an unofficial session-cookie path. Operator isolation is half built (RLS TODO, db/README.md:66-68).
4. Top risk 3 (3 GAP + 1 PARTIAL): the tenant texting flow ("Your tenants text. The system picks it up", "A text line your tenants can reach any time", "Add your tenants... Nothing to install", "Always-on AI agent for tenants") has no Twilio client, no own number and no STOP/HELP handling. There is no portal form to add tenants by phone and no AI that replies to tenants. Today it reads PadSplit inbox threads only.
5. Other PARTIALs worth fixing soon: paid guides are emailed only if the buyer's browser loads the success page (there is no Stripe webhook); the newsletter has no list and no sender; every /vision "In development" item exists in .BOS core, but PM.BOS has 0 `bos_core` imports, so "PM.BOS live" as an XX.BOS pack isn't true yet.

Scope: index, property-management, talk, apply, free, vision and wyatt (visible text, meta, alt text). Code: pmbos main at 3f74353 (other branches noted), bos main at 4ae7069, site api/. Left out: the /apply simulator. Its button is never unhidden in apply.js (only `hidden=true`, apply.js:103), consistent with DECISIONS 2026-11-03, so it isn't a live promise. Alt text holds only "Teroir" / "Wyatt Horton", with no claims.
