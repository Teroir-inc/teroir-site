What the door uses today.

  • MCP over Streamable HTTP: https://agent.teroir.com/mcp
  • Tools: catalog, request_work, check_status
  • Sign-in: OAuth 2.1 with PKCE (S256), by Client ID Metadata Document or dynamic client registration
  • Request signing: HTTP Message Signatures (RFC 9421), with a key we hold for you
  • Receipts: JWS (Ed25519) over canonical JSON (RFC 8785)
  • Approval: a person signs off with a passkey (WebAuthn)
  • States in check_status: “received”, “received by Teroir; a reply is being prepared”, “replied”, “declined by Wyatt”, “not accepted”
